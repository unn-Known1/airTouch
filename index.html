How to use on iPhone:
1. Serve this file over https:// (GitHub Pages, Vercel, Netlify, or npx serve with tunnel).
2. Open in Safari.
3. Tap Enable Gyro → Allow.
4. For installable PWA, this also works when added to Home Screen.

Permissions: iOS 13+ needs DeviceOrientationEvent.requestPermission() and DeviceMotionEvent.requestPermission() both triggered by a user gesture. No gesture = silently no data.
