TV Connection (Remote App logic)
1. TV must be on same WiFi. 2. On TV, a pairing prompt appears — note PIN. 3. Bridge handles TLS 6466 (like Google TV app) — no ADB needed. Run node android-tv/remote-bridge.js --tv-ip 192.168.1.20 --room 5576 on a laptop/Pi on same WiFi, or use the bridge’s WebSocket relay.
