AirTouch BLE HID — Experimental

Try to make your phone act as a Bluetooth mouse for TV/laptop via navigator.bluetooth + HID (0x1812).
No APK/npx — but browsers can only be central (scan), not peripheral (advertise). So this page (on TV/laptop) scans for a phone/dongle that exposes HID. True phone-as-mouse without dongle is not possible in pure web today — this demo shows the limit and the dongle workaround.

  • TV/laptop must support BLE HID and be discoverable
  • Phone alone cannot advertise as HID from browser — needs a $3 ESP32 HID dongle + WiFi HID or native
ready

If you see “Web Bluetooth not supported” — use Chrome/Edge on Android/Windows, not iOS Safari (iOS has no Web Bluetooth).
