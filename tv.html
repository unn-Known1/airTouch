How Android TV system control works

This page shows a virtual cursor inside the browser. For true system-wide control (move Android TV OS cursor, Back/Home/Vol), install the companion AirMouse APK on your TV:
APK runs a WebSocket client + AccessibilityService to inject MotionEvent / KeyEvent.
Web-only mode is perfect for demo / controlling web apps on TV without APK.
