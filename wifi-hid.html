AirTouch WiFi HID — No APK/npx

Goal: global OS cursor via WiFi, without installing APK or running npx on the TV/laptop.

Why pure WiFi can’t be global (browser sandbox)

A page at https://unn-known1.github.io/airTouch/ on your TV/laptop can receive phone gyro via PeerJS/WebSocket and move a virtual cursor inside that tab (we already do in index.html TV tab).
But it cannot call SendInput/dispatchGesture outside the tab — that needs OS permission. So WiFi-only global needs one tiny receiver that has that permission.

Smallest “no APK/npx” receivers:

  • ESP32 WiFi HID dongle ($3–6) — plug into TV/laptop USB, enumerates as real mouse. This page (over WiFi, PeerJS room) sends dx,dy → dongle → HID reports → moves real cursor. No software on TV/laptop at all.
  • Bookmarklet / PWA with one-time Web Serial permission — page uses navigator.serial to talk to the same dongle, still no install.

Try it: WiFi dongle mode

  1. Flash ESP32 with airtouch-wifi-hid.ino (provided in repo wifi-hid/ — WiFi + HID over USB)
  2. Plug dongle into TV/laptop USB
  3. Open this page on phone and on TV/laptop? No — only phone needs page. Dongle auto-joins your PeerJS room ---- via WiFi.
  4. Phone gyro now → WiFi → dongle → real HID mouse
ready

Alternative: “Fake global” — fullscreen web launcher (no dongle, no install, but only inside page)

We can make index.html TV tab go fullscreen and render a launcher that looks like the system UI. Phone moves cursor inside that fullscreen page — feels global, but can’t reach Netflix outside page. Good for demos, not for real global.
